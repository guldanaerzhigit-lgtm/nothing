# NOTHING

**Nothing is what it seems.**

A minimal React + Vite PWA experiment: one black screen, one white dot, and a few hidden interactions.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`

## Interactions

- Tap the dot.
- Double-tap the dot.
- Press and hold the dot.
- Stay still and wait.
- On supported phones, try a gentle shake.
- There is one other detail near the lower-right edge.

Discovered secrets are stored locally in the browser. No account or backend is required.
